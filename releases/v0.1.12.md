# AI Fence CLI v0.1.12 Preview

This preview includes the continuation recovery fixes prepared for v0.1.11.
When upstream response state is missing, the proxy returns the standard
`previous_response_not_found` signal so supported Codex clients can resend their
complete history. Tool-output provenance and supported delivery metadata remain
intact; incomplete deltas are never forwarded as new conversations.

The accompanying gateway update preserves native Chat Completions provider,
reasoning and plugin controls, including explicit false, zero and empty values.
Actual upstream provider and supported usage/cost receipts survive response
processing. Provider-reported charges remain separate from configured gateway
budget estimates. Requests with these controls reject lossy protocol conversion
and disable redirects and automatic compatibility retries. Live routing, privacy,
precision and price enforcement remain the upstream provider's responsibility.

Managed desktop updates and idle reconnects, stable native state homes, optional
checkpoints and persistent named workspaces remain available. Saved desktop chats
may need reopening after reconnect; native recovery depends on the Codex version.
The separate application runtime remains disabled by default.

Targets: Linux x86_64 (glibc 2.34 or newer), Windows x86_64 and macOS Apple Silicon. The macOS preview
uses an ad-hoc signature, requires macOS 12 or newer, and is not Developer ID
signed or notarized. Checksums identify release content, not a publisher
signature. Native platform and live-provider checks are separate from generated
loopback regressions. This release does not authorize private-media transfers.

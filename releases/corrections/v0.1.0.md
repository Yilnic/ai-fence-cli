## AI Fence CLI v0.1.0 Preview

This is the first public preview of the AI Fence CLI launcher workspace.

### Download correction — 2026-09-05

The official binary links below point to the current CLI release. The
files have changed since this preview was published, while the advertised
binary version remained `0.1.0`. The SHA-256 values previously listed in these
release notes therefore no longer identify the files served by those links
and have been removed.

These are moving current-release links, not archived binaries for v0.1.0. Use
the corresponding current manifest to check a current download. A matching
manifest checksum does not establish that the file is the original preview
binary. This release has no attached official binary assets; the `v0.1.0` tag
identifies the public source snapshot.

For fixed binaries and checksums, use [v0.1.1](https://github.com/Yilnic/ai-fence-cli/releases/tag/v0.1.1).

### Included in this repository

- Launcher configuration and managed profile support
- Local HTTP and WebSocket proxy transport
- Authentication and credential handling
- Codex and Claude Code launch integration
- Shared gateway API contracts
- Model capability and pricing metadata
- Public CI and source-boundary checks

### Install the current official CLI on Linux

```bash
curl -fsSL https://ai.yml.world/install.sh | bash
codex-fenced
```

Documentation: https://ai.yml.world/docs

### Current official binaries

The official CLI combines this public launcher workspace with the AI Fence
processing engine. The complete executable is distributed separately under
the AI Fence product license.

- [Linux x86_64 download](https://ai.yml.world/downloads/ai-fence-cli-linux-x86_64)
- [Current Linux manifest, including SHA-256](https://ai.yml.world/downloads/ai-fence-cli-manifest.json?target=linux-x86_64)
- [Windows x86_64 download](https://ai.yml.world/downloads/ai-fence-cli-windows-x86_64.exe)
- [Current Windows manifest, including SHA-256](https://ai.yml.world/downloads/ai-fence-cli-manifest.json?target=windows-x86_64)

If a downloaded file does not match its manifest, do not run it; fetch the
manifest and file again to rule out a deployment occurring between requests,
and report any persistent mismatch.

### Source boundary

The MIT-licensed source in this repository contains the public launcher,
transport, authentication, contracts, and model metadata. It intentionally
does not contain the proprietary request-processing engine and does not build
the complete official executable by itself.

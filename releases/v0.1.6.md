## AI Fence CLI v0.1.6 Preview

Managed Codex runs in a Linux guest can explicitly request bounded key
replacement and replace their working gateway key once. The launcher installs
a valid reply atomically, and the next proxy request uses the replacement.
Both keys retain the same run, rental, source authority, budget and expiry;
the original remains available for cleanup.

Replacement retries stop at the original issuance deadline. Lost, invalid or
denied replies leave the original working key file unchanged. There is no
periodic key rotation, and ordinary native runs keep their existing behavior.

Synthetic CLI, proxy and database tests cover replacement, retained cleanup,
revocation and shared quota/cost limits. Release preparation verifies the three
artifact hashes and sizes and runs the Linux executable's version check.
Native Windows/macOS execution and real-provider browser login are separate
checks.

immutable; checksums identify content, not a publisher signature. The macOS
preview is ad-hoc signed, without Developer ID signing or notarization.

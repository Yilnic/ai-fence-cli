## AI Fence CLI v0.1.7 Preview

Codex desktop and native WSL now have an opt-in `codex-desktop setup` target.
It packages a supervised stdio adapter and runtime helper, keeps the genuine
native Codex executable and an explicitly selected durable state home, and
pins each app-server to its own local proxy. Concurrent launches and upgrades
preserve conversation history and native subscription authentication.

Native standalone named tool outputs, including cross-chat messages without
`call_id`, retain tool provenance, namespace, identity and supported metadata
through forwarding and replay. Invalid inputs receive a structured local
validation error with no upstream call or transient retry.

Optional approved-project Btrfs checkpoints retain the current working
directory. Persistent writable workspaces require an explicit opt-in, protect
dirty and chat-linked state, and never restore on ordinary resume. Doctor,
adoption/recovery previews, rollback and a Windows session launcher are included.

Setup requires Linux/WSL and Python 3.11+. Native protocol validation used Codex
0.162.1 with fixture credentials and no model inference. Windows desktop
discovery remains version dependent. Real OAuth refresh and native
Windows/macOS execution require separate checks; writable isolation rejects
nested subvolumes and external/shared Git metadata. Existing app-servers keep
their current runtime until deliberately reconnected.

immutable; checksums identify content, not a publisher signature. The macOS
preview is ad-hoc signed, without Developer ID signing or notarization.

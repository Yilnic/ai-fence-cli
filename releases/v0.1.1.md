## AI Fence CLI v0.1.1 Preview

This preview publishes fixed official binaries for Linux x86_64, Windows x86_64,
and macOS Apple Silicon, with a SHA-256 manifest for each platform.

### Downloads and verification

- [Linux x86_64](https://github.com/Yilnic/ai-fence-cli/releases/download/v0.1.1/ai-fence-cli-linux-x86_64)
- [Windows x86_64](https://github.com/Yilnic/ai-fence-cli/releases/download/v0.1.1/ai-fence-cli-windows-x86_64.exe)
- [macOS Apple Silicon](https://github.com/Yilnic/ai-fence-cli/releases/download/v0.1.1/ai-fence-cli-macos-aarch64)
- [SHA256SUMS](https://github.com/Yilnic/ai-fence-cli/releases/download/v0.1.1/SHA256SUMS)

Download the selected executable and `SHA256SUMS` from this release. On Linux,
run `sha256sum --ignore-missing -c SHA256SUMS` in that directory and require the
selected executable to report `OK` before running it. On macOS, compare
`shasum -a 256 ai-fence-cli-macos-aarch64` with its entry in `SHA256SUMS`.
On Windows, compare `Get-FileHash .\ai-fence-cli-windows-x86_64.exe -Algorithm SHA256`.
Checksums identify content; they are not a publisher signature.

The installer at `https://ai.yml.world/install.sh` follows the currently selected
release. To select this exact version, use the asset links above. These assets
will not be replaced by subsequent backend deployments; binary fixes require a
new release version.

### Validation and preview limits

Publication verifies all three binaries against the committed release plan and
checks the Linux executable's version. The release remains a preview: native
Windows/macOS application smoke tests and real-provider compatibility are not
established by the publication checks. macOS requires Apple Silicon and macOS
12 or later; the executable is ad-hoc signed, without Developer ID signing or
Apple notarization.

The MIT-licensed repository contains the public launcher, transport, shared
contracts, and metadata. The official executable also includes the separately
distributed AI Fence processing engine; this repository does not build the
complete official executable by itself.

The v0.1.0 source tag remains available, but its original announcement linked
moving downloads and did not archive official binaries. Use this release's
assets for reproducible downloads.

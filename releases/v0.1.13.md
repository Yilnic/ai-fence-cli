# AI Fence CLI v0.1.13 Preview

New server-backed setup suggests `https://ai.yaaf.de` for production and
`https://ai-dev.yaaf.de` for the DEV installation channel. Saved custom server
addresses and explicitly selected desktop update sources remain unchanged.

DEV uses separate `*-dev` commands and configuration rather than a synthetic
profile named dev. Installing or updating one channel preserves the other
channel, and explicit channel selection takes precedence over an inherited
opposite-channel environment. New named-profile setup also suggests the
appropriate server address.

The optional desktop adapter follows its selected channel and update source
without replacing native authentication, history, workspace approvals or
checkpoint policy. Switching an existing adapter's channel remains an explicit
operation; updating the CLI does not switch it or force a reconnect.

Targets: Linux x86_64 (glibc 2.34 or newer), Windows x86_64 and macOS Apple
Silicon. The macOS preview uses an ad-hoc signature, requires macOS 12 or newer,
and is not Developer ID signed or notarized. Checksums identify release content,
not a publisher signature. Native platform and live-provider checks remain
separate from local protocol regressions.

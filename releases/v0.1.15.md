# AI Fence CLI v0.1.15 Preview

Managed repository bases infer the current Git project's remote, upstream
default branch and private Btrfs storage. The store may live on any eligible
mounted Btrfs filesystem. Ambiguous or unavailable storage requires an explicit
choice; the CLI does not format, mount or elevate.

A clean managed checkout publishes immutable base generations. New named
workspaces start from a refreshed generation with their own complete Git
metadata; resuming an existing name preserves its files and native history.
Existing active checkouts are not migrated automatically.

Bounded committed-source listing, reading, literal search and generation change
lists are available through the standalone workspace engine. Finite leases
protect individual consumers' source views. Cleanup removes eligible unused
base generations while preserving writable workspaces and recovery checkpoints.
Application authentication and permission policy stay outside the engine.

This release also includes the persistent Btrfs identity checks described in
the v0.1.14 notes, preserving registered connections after a remount changes
Linux device numbers.

Targets: Linux x86_64 (glibc 2.34 or newer), Windows x86_64 and macOS Apple
Silicon. Btrfs workspace operations require Linux or WSL; Windows helpers route
workspace management through WSL. The macOS preview uses an ad-hoc signature,
requires macOS 12 or newer, and is not Developer ID signed or notarized.
Checksums identify release content, not a publisher signature. Native platform
and live-provider checks remain separate from local protocol regressions.

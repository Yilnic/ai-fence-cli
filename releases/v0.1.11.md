# AI Fence CLI v0.1.11 Preview

This release fixes continuation recovery when a Codex desktop/CLI chat loses its
upstream WebSocket and AI Fence cannot reconstruct the previous response state.
The proxy returns the standard `previous_response_not_found` recovery signal,
including on HTTP and reconnect paths, so clients can resend their complete
history. Incomplete tool-output deltas are never forwarded as fresh conversations.
Original instructions, standalone named tool-output provenance and supported
delivery metadata remain intact during full-context recovery.

This release retains managed desktop automatic updates and idle reconnects,
stable native state homes, optional checkpoints and named workspaces. Native
client recovery depends on the installed Codex version; reopening saved desktop
chats may still be necessary after a managed reconnect. The separate application
runtime merged for 0.1.10 remains disabled by default.

Preview targets: Linux x86_64, Windows x86_64 and macOS Apple Silicon. The macOS
preview uses an ad-hoc signature and requires macOS 12 or newer; it is not Apple
Developer ID signed or notarized. Checksums identify release content, not a
publisher signature.
